01 · Project Overview

一次以「行为心理学」为底色的产品设计实验

从群体痛点与市场缺口出发，用 MVP 精益思想锁定核心价值，围绕大学生职业成长全链路展开完整的网页端产品设计。

群体背景18–24 岁大学生的职业焦虑

当代在校大学生普遍陷入职业焦虑：对未来方向认知模糊、长期目标宏大难以落地、项目与实习记录零散、缺少持续行动的动力。

市场背景求职工具的「毕业季」局限

市面上绝大多数求职工具聚焦毕业阶段的简历投递，缺少一款陪伴大学生长期成长、打通「方向探索 → 任务执行 → 成果沉淀」全链路的轻量化网页工具。

Core Value Proposition · 核心价值主张

将模糊的职业焦虑，转化为可持续执行的长期成长行动。

产品不只是任务清单，更是大学生职业成长的「操作系统」——整合职业方向探索、目标拆解、任务打卡、成长档案沉淀功能，覆盖从迷茫到行动的全周期。

01

UX 目标

降低职业规划的行动门槛，通过激励式体验提升用户持续行动意愿，缓解职业迷茫带来的情绪内耗。

02

设计产出目标

完成网页端 MVP 核心页面完整原型，搭建清晰的信息架构与流畅用户路径，让产品可演示、可验证。

03

差异化目标

以行为心理学作为底层设计逻辑，打造区别于普通清单工具、求职平台的独特激励式成长体验。

03 · Competitive Analysis

四大赛道对标，挖出市场空白

选取简历工具、AI 求职助手、招聘求职社区、职业测评规划四类代表性产品（职徒简历 / 职悟空 / 牛客网 / 择业宝），确认 Career OS 的差异化空位：缺的不是「找工作」，而是「从迷茫到行动的成长闭环」。

Career OS本产品 · 概念

大学生职业探索成长网页工具，把职业焦虑转化为可持续成长行动。

差异化定位

打通「探索–目标–执行–沉淀」完整闭环；以行为心理学做激励体验；聚焦长期成长而非短期投递。

当前局限

MVP 概念设计；暂未开展真实用户调研。

职徒简历简历工具

面向大学生的简历制作与求职辅导工具。

可学习

简历模板丰富，AI 优化成熟；STAR 经历引导专业。

应避免

只聚焦简历产出，缺少长期目标管理与成长进度追踪；不适合早期探索。

职悟空AI 求职助手

应届生校招 AI 求职陪伴工具，依托智联岗位库。

可学习

AI 记忆用户背景、持续迭代方案；把 AI 嵌入完整用户流程。

应避免

只服务「已经要找工作」的阶段；重心是投递岗位，无目标拆解与成长沉淀。

牛客网求职社区+题库

技术向求职社区与笔试面试题库平台。

可学习

UGC 沉淀真实同辈经验；内容标签清晰便于检索。

应避免

偏重技术岗，非技术内容薄弱；没有测评、目标管理与成长档案。

择业宝高校测评平台

高校校内职业规划测评平台，报告体系成熟。

可学习

测评问卷逻辑严谨、维度完整；输出结构化报告。

应避免

报告输出即流程结束，缺少把规划转化为持续行动的闭环。

06 · Behavioral Psychology in UX

把心理学理论，翻译成交互与文案

这是本项目最大的差异化优势：全部交互、反馈、文案设计依托心理学理论，从底层提升用户行动意愿，解决「想规划但难以坚持」的用户难题。

8 大行为心理学理论 × 8 项落地机制

自我效能感、及时反馈、目标梯度、承诺一致、社会认同、损失厌恶与沉没成本、情绪激励与陪伴感、低门槛启动——每一项都落到具体的交互定义与文案中。

8大理论落地
01

自我效能感

持续完成微小任务，建立「我可以做到」的信心。

具体交互任务完成弹窗「你已连续完成3天，继续保持！」（2 秒自动消失）；首页「已完成成果」按时间倒序展示。
02

及时反馈机制

即时正向反馈，持续激发行动动力。

具体交互打卡后进度条 65% → 70%（0.8s ease-out）；每周一推送「上周成长小结」；成就解锁触发 1.5s 撒花动效。
03

目标梯度效应

用户感知自己不断靠近目标时，坚持意愿显著提升。

具体交互里程碑分段进度条，完成节点显示 ✓ 并变色；完成度 80% 时出现「还差2项即可完成本周目标」；临近里程碑呼吸动效。
04

承诺一致原则

主动写下目标后，人们倾向维持行为统一。

具体交互「写下你的承诺」可选输入框；每月 1 号承诺确认弹窗；公开打卡开关显示「已有128位同学公开打卡」。
05

社会认同效应

看到同龄人同类探索行为，增强参与动力。

具体交互推荐卡显示「同专业已有32位同学选择此方向」；社区默认筛选「同专业」；案例采用「背景–行动–结果」三段式。
06

损失厌恶 & 沉没成本

人不愿意丢失已经积累的成果。

具体交互断卡后温和提示条「你的连续打卡记录停在了23天」；删除目标确认「将丢失该目标下的12条打卡记录」。
07

情绪激励与陪伴感

职业探索伴随大量焦虑情绪，需要陪伴而非冰冷工具。

具体交互空状态插画 + 鼓励文案；AI 默认使用「我们一起」「我陪你」；22:00 后打卡显示「夜深了，完成任务就早点休息吧」。
08

低门槛启动

降低首次进入与持续操作的认知负担。

具体交互测评每页 4 题 + 进度指示；Hero「开始探索」直达测评；注册仅 3 步、全程不超过 30 秒。
设计权衡 · 拒绝过度游戏化

积分、排行榜可以提升活跃度，但目标用户已被求职内卷焦虑裹挟，本产品刻意避开强竞争类游戏化设计——不设排行榜，聚焦个人成长的纵向对比，而非同龄人横向比拼，避免加重焦虑。

交互示例 · 打卡正向反馈

点击任务试试

按照文档中的交互规格实现：任务完成后进度条从 65% 滚动到 70%（时长 0.8s，ease-out 缓动），并弹出正向反馈弹窗（2 秒后自动消失）。

对应机制：自我效能感 + 及时反馈 · 自我效能感弹窗文案与进度动效均取自原型设计规格

STAGE 1

8 个核心页面中低保真原型

每张卡片对应一个页面的布局逻辑与心理学设计巧思

01注册登录页

极简单列居中布局，视觉焦点集中在「确认登录」唯一行动点。

心理学注册仅需手机号（低门槛启动）；「欢迎回来，继续你的职业成长旅程」触发承诺一致。

02首页

身份认同 → 目标牵引 → 任务执行；Hero 渐变卡 + 里程碑式进度条 + AI建议/我的安排 Tab。

心理学「未来的产品设计师」身份暗示（自我效能）；目标梯度效应；实时进度刷新（及时反馈）。

03职业探索页

上到下信息流：搜索栏 + 快捷入口 + 岗位推荐卡片 + AI 规划入口 + 测评模块。

心理学环形百分比进度直观反馈；AI 生成按钮弱化操作压力；模块化卡片降低信息过载。

04职业准备页

职业准备度环形进度卡片 + 2×2 功能卡片 + 底部求职工具双卡片。

心理学环形进度完成度激励；把庞大求职任务拆解为独立小模块，降低畏难情绪。

05社区页

顶部标签筛选栏 + 纵向流式卡片信息流，交互控件统一置于卡片底部。

心理学UGC 真实经验发挥社会认同；标签分类降低筛选成本；点赞收藏满足素材留存心理。

06我的页面

个人信息头部卡 → 三组量化数据 → 纵向功能菜单，自上而下流转。

心理学连续学习 / 完成任务 / 掌握技能量化（成长反馈）；损失厌恶提醒坚持；会员入口前置。

07AI 对话页

顶部对话主区域 + 底部输入区；核心创新「提示词撰写器」以预设模板替代空白输入框。

心理学直接解决「不知道问什么」的冷启动，把构思问题转为选择，降低门槛、提升自我效能。

08设置页

通用设置 / 消息通知 / 账号管理 / 隐私与数据安全 / 帮助客服，折叠展开节省空间。

心理学简洁舒适的体验；每次职业探索的思考过程被有序保存，形成可回溯的成长知识库。

08 · Usability Testing

一份可落地的可用性测试方案

原型完成后计划开展可用性测试，围绕「核心路径通畅、激励机制有效、信息架构清晰」三个核心问题，验证设计合理性并为迭代提供依据。

QUESTION 01

核心路径是否通畅：用户能否独立完成「职业探索 → 目标创建 → 任务拆解 → 打卡执行」主流程，无明显卡点。

QUESTION 02

激励机制是否有效：进度可视化、即时反馈、身份暗示等心理学设计是否真的提升行动意愿与持续使用意向。

QUESTION 03

信息架构是否清晰：用户能否快速定位所需功能，页面信息层级是否造成认知负担。

01
完成测评并获取岗位推荐

场景：大一新生，对未来职业方向感到迷茫。独立找到测评入口 → 完成问卷 → 看到岗位推荐结果 → 说出至少 1 个推荐岗位。

完成今日任务打卡 → 看到进度条 / 百分比更新 → 成功进入成长档案页面；重点观察打卡是否一步完成、反馈是否被明确感知。

使用提示词模板获取 AI 建议

预计耗时 4–6 min

09 · Reflection

项目复盘：收获、局限与下一步

一次完整的 UX 全链路实践，也诚实地记录它的边界。

项目收获

  • 完整走完标准 UX 全链路：痛点挖掘 → 需求梳理 → 用户画像 → 策略 → 信息架构 → 流程 → 原型 → Demo 落地 → 测试方案 → 复盘，建立系统化设计思维。
  • 将行为心理学理论落地到界面、交互与文案设计，形成差异化亮点。
  • 熟练掌握「手绘草图 → 低保真 → AI 视觉协作 → 高保真定稿」现代化设计工作流。
  • 学会用 MVP 精益思想管控项目边界，避免功能过度设计。

项目局限

  • 用户需求基于群体共性归纳，尚未开展大规模深度访谈与问卷调研。
  • 仅完成 MVP 核心页面原型，社区、商业化模块停留在策略构思，无视觉产出。
  • 暂无真实用户测试数据，优化方案等待可用性测试验证。

后续优化计划

  • 招募在校大学生开展可用性测试，用真实数据校验用户画像与需求假设。
  • 依据用户反馈迭代网页信息层级与交互细节。
  • 持续打磨激励型交互与文案，强化产品陪伴感。
